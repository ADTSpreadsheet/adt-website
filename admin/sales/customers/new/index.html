เพิ่มลูกค้าใหม่

กรอกข้อมูลที่จำเป็นสำหรับสร้าง Customer Master เพื่อใช้ต่อในใบเสนอราคา สัญญา และเอกสารธุรกิจ

← กลับ Customers / Vendor List

1. ประเภทลูกค้า

เลือกประเภทก่อน ระบบจะปรับช่องข้อมูลให้เหมาะกับลูกค้า

2. ข้อมูลลูกค้า

ข้อมูลชุดนี้จะเป็น Master Data สำหรับออกเอกสารในระบบ

3. ข้อมูลผู้ติดต่อ

ใช้สำหรับติดต่อประสานงานและจัดทำเอกสาร

4. สถานะลูกค้า

ใช้สำหรับควบคุมการทำธุรกรรมและประเมินความเสี่ยง

5. เอกสารประกอบ

รอบนี้เป็น UI สำหรับเลือกไฟล์ก่อน ภายหลังจะเชื่อม Supabase Storage แบบ Private

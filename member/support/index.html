ยังแก้ปัญหาไม่ได้?

ส่งรายละเอียดปัญหาให้ทีม ADT พร้อมประเภทปัญหาและข้อมูลที่เกี่ยวข้อง ระบบ Ticket จริงค่อยเชื่อมในขั้นต่อไป

คำถามที่พบบ่อย

คำตอบเบื้องต้นสำหรับปัญหาที่สมาชิกพบเป็นประจำ

ให้ตรวจสอบสิทธิ์ License ในหน้า “โปรแกรมของฉัน” ก่อน หากต้องการย้ายเครื่องหรือ Activation ใหม่ ให้ติดต่อทีม ADT ผ่าน LINE พร้อมแจ้ง Member ID และชื่อโปรแกรม
ตรวจสอบ Version ของ Excel และไฟล์ที่ดาวน์โหลดก่อน หากยังไม่สามารถเปิดได้ ให้ส่ง Screenshot ของ Error ผ่าน LINE ADT Support เพื่อให้ทีมงานตรวจสอบ
ไปที่เมนู “การชำระเงิน” เพื่อดู Order History สถานะการชำระ และเอกสารที่เกี่ยวข้องกับคำสั่งซื้อของคุณ
ใช้เมนู “ลืมรหัสผ่าน” ที่หน้า Login สมาชิก หากยังไม่สามารถเข้าใช้งานได้ให้ติดต่อ LINE ADT Support
หลังระบบยืนยันสิทธิ์แล้ว เอกสารจะอยู่ในเมนู “ใบประกาศ” ของบัญชีสมาชิก
